# ペンキ塗総業 デモサイト

GitHub Pages 用の静的サイトです（ビルド不要）。

## 公開手順
1. GitHub で新しいリポジトリを作成（例：`penkitosou-demo`）
2. このフォルダの中身（index.html・assets フォルダなど）をリポジトリ直下にアップロード
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/penkitosou-demo/` で公開されます

※ 検索エンジンに載らないよう、全ページに noindex を設定しています。本番公開時は外してください。
※ 写真・口コミ・施工事例・一部の数字は仮のものです。
